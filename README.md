# ЛР1. Сравнение LLM и предобученных моделей для прогноза спроса на метро

Дисциплина «Прикладные задачи машинного обучения». Лабораторная работа 1.

**Тема ВКР:** «Разработка модели динамического прогнозирования спроса на городской транспорт
с учётом пространственных и временных зависимостей».

**Задача лабораторной:** сравнить 8 моделей (6 предобученных моделей для временных рядов и 2 текстовые LLM)
по единому протоколу на прогнозе почасовых входов в метро Нью-Йорка на 24 часа вперёд,
выбрать лучшую по заранее заданному правилу и применить её ко всей сети станций.

## Структура

```
PROTOCOL.md        протокол сравнения (зафиксирован до запуска моделей)
labkit.py          общий код: данные, подвыборка, окна, метрики, журнал запусков
notebooks/         ноутбуки, запускаются на Kaggle по порядку номеров
results/           результаты, скачанные из Output ноутбуков Kaggle
report/            обзор литературы и отчёт
```

## Данные

Приватный Kaggle-датасет `vkr-transit-lab`, версия v1: почасовые входы по 424 станциям метро
Нью-Йорка за 01.01.2023 – 24.09.2026 (MTA Open Data), календарь, погода (Open-Meteo), граф станций.
Подготовлены в рамках работы над ВКР; описание — в README и `data_passport.md` внутри датасета.

## Как повторить

1. На Kaggle создать ноутбук из `notebooks/lab_00_setup.ipynb`, подключить датасет `vkr-transit-lab`,
   запустить (Save & Run All). Он сохраняет `labkit.py`, подвыборку `subset.json` и сезонный наивный прогноз.
2. Остальные ноутбуки запускаются по порядку номеров; в каждом подключаются датасет и вывод `lab-00-setup`.
3. Результаты каждого ноутбука (`results/`) скачиваются из Output в папку `results/` репозитория.
